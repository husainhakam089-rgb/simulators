# مشغّل ويندوز صغير (.exe)

ملف تنفيذي بحجم **~١.٦ ميغابايت** لكل تطبيق، بدل ٨٥ ميغابايت في
`desktop/`.

| الملف | التطبيق |
|---|---|
| `dist/phy-sixth-1-2.exe` | المتسعات + الحث الكهرومغناطيسي |
| `dist/phy-sixth-3-4.exe` | التيار المتناوب + الموجات الكهرومغناطيسية |

## الفرق عن نسخة `desktop/`

| | `desktop/` | `launcher/` |
|---|---|---|
| الحجم | ٨٥ م.ب | **١.٦ م.ب** |
| يفتح في | نافذة خاصة بالتطبيق | متصفح الجهاز |
| يحمل محرك عرض | نعم (Chromium) | لا |

٩٩٪ من حجم نسخة `desktop/` محرك Chromium. هذا المشغّل لا يحمل محركاً:
يستعمل المتصفح الموجود على الجهاز، فيبقى بحجم التطبيق نفسه تقريباً —
وهذا ما يجعله صالحاً للإرسال عبر واتساب أو نسخه على أي فلاش.

## كيف يعمل

ملف التطبيق (`phy-sixth-1-2.html`) مدمج داخل الملف التنفيذي كمورد
`RCDATA`. عند النقر المزدوج:

1. يُكتب الملف إلى `%LOCALAPPDATA%\PhySixth\`.
2. يُفتح بالمتصفح الافتراضي عبر `ShellExecuteW`.

تُعاد الكتابة في كل تشغيل، فأي نسخة أحدث من التطبيق تصل للمستخدم بمجرد
استبدال الـ exe. وإن كان الملف مفتوحاً بالمتصفح وتعذّرت الكتابة، يُفتح
الموجود بدل أن يفشل التشغيل.

## البناء

```bash
sudo apt-get install mingw-w64          # مرة واحدة
python3 launcher/build-launcher.py      # التطبيقان
python3 launcher/build-launcher.py phy-sixth-1-2
```

يأخذ السكربت نسخة كل تطبيق أحادية الملف كما هي، فلا توجد نسخة ثانية من
شيفرة التطبيق يمكن أن تفترق عن الأصل.

## ملاحظات

- الملف **غير موقّع رقمياً**، فقد يعرض ويندوز تحذير SmartScreen أول مرة:
  «مزيد من المعلومات» ثم «تشغيل على أي حال».
- يعمل على ويندوز ٦٤ بت. لا يحتاج تثبيتاً ولا إنترنت ولا أي ملف بجانبه.
