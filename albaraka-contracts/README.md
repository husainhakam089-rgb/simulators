# تطبيق عقود ووصولات الآلات الزراعية
### معرض البركة لتجارة السيارات الحديثة

تطبيق أندرويد يطبع **عقد بيع كامل على ورقة A4** للترتكترات والحاصدات، و**وصلاً صغيراً على نصف ورقة** للأدوات والملحقات — بنفس شكل الدفتر الورقي لكن بخط طباعة مرتب، وبإدخال سريع يعتمد على الاختيار بدل الكتابة.

يعمل بالكامل **بدون إنترنت**، وكل البيانات محفوظة على الجهاز نفسه.

---

## تشغيل سريع

### على الحاسبة (للتجربة والتعديل)
```bash
cd albaraka-contracts
npm install
npm run serve          # ثم افتح http://localhost:5173
```

### بناء ملف APK
البناء يحتاج **Android Studio** أو **Android SDK** على الجهاز:

```bash
cd albaraka-contracts
npm install
npx cap sync android
cd android && ./gradlew assembleDebug
# الملف الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```

**الطريقة الأسهل — بدون تثبيت أي شيء:** ملف `.github/workflows/android-apk.yml` يبني الـ APK تلقائياً على GitHub عند كل رفع. افتح تبويب **Actions** في المستودع، اختر آخر تشغيل، ونزّل الملف من قسم **Artifacts**.

## ما الذي أُنجز من الخطة

| المرحلة | الحالة |
|---|---|
| **الأولى** — الأساس: واجهة عربية RTL، إعداد Capacitor، قاعدة بيانات محلية | ✅ |
| **الثانية** — الإعدادات والقوائم القابلة للتوسع | ✅ |
| **الثالثة** — شاشة العقد الكامل | ✅ |
| **الرابعة** — الطباعة: قالب A4، تحويل PDF، النسخ، الإرسال للطابعة، المشاركة | ✅ برمجياً — يبقى **الضبط النهائي على ورق حقيقي** |

الحسابات وجدول الأقساط ما زالت مؤجلة كما في الخطة.

## الشاشات

- **الرئيسية** — «ماذا تبيع؟» اختيار آلية يفتح شاشة العقد، واختيار أداة يفتح شاشة الوصل.
- **العقد** — الصور والتاريخ، بيانات الآلية، السنوية، المبالغ، الملاحظات، بيانات البائع والمشتري، النسخ.
- **الوصل** — نفس المنطق بحقول أقل، مع خيار وصلين في الورقة الواحدة وخط قص بينهما.
- **السجل** — بحث باسم الزبون أو رقم العقد أو رقم الشاصي، وإعادة طباعة أي مستند قديم.
- **الإعدادات** — بيانات المعرض، صور الرأس، العدادات، الطابعة، النسخ الافتراضية، شروط العقد، القوائم، النسخة الاحتياطية.

## السلوكيات المهمة

**رقم العقد** تلقائي متسلسل وغير قابل للتعديل. يبدأ من الرقم المكتوب في الإعدادات (`آخر رقم عقد مستعمل`) — اضبطه على آخر رقم في الدفتر الورقي مرة واحدة فقط.

**القوائم تكبر مع الشغل**: كل قائمة فيها خيار «أخرى» للكتابة الحرة. بعد حفظ المستند يسأل التطبيق مرة واحدة: «تريد إضافتها للقائمة؟» — نعم تجعلها خياراً ثابتاً، لا تُبقيها في هذا المستند فقط.

**منع تكرار الأسماء**: عند الكتابة في «أخرى» تظهر الخيارات المشابهة الموجودة مسبقاً (تكتب «ماسي» فيظهر «ماسي فيركسون»). المقارنة تتجاهل الهمزات والتاء المربوطة والتشكيل.

**الكبسولات**: تُعرض العشرة الأكثر استعمالاً، والباقي خلف زر «المزيد» مع بحث. الترتيب يتغيّر تلقائياً حسب الاستعمال الفعلي.

**العجلة الدوارة** للتاريخ والوقت وسنة الموديل، تفتح على القيمة الأكثر احتمالاً (اللحظة الحالية / سنة قريبة)، **وتقبل الكتابة المباشرة** أيضاً.

**نوع الهوية يقرر الحقول**: بطاقة وطنية تُظهر رقم البطاقة فقط، وهوية الأحوال القديمة تُظهر السجل والصفحة.

**اقتراح الزبائن**: كتابة أول حرفين من اسم زبون سابق تعرض بياناته كاملة، واختياره يملأ الهوية والدائرة والعنوان والموبايل دفعة واحدة.

**المبلغ** يُحوَّل إلى حروف تلقائياً («خمسة وعشرون مليون دينار عراقي لا غير»)، و**الباقي** يُحسب تلقائياً.

## الطباعة

المستند يُبنى **مكتفياً بذاته**: الخطوط العربية والأنماط مدمجة داخله، والمقاسات بالمليمتر — فيطلع بنفس الشكل على أي طابعة.

**الطريقة الأولى (الافتراضية والمضمونة):** نظام الطباعة المدمج في أندرويد. تظهر نافذة أندرويد فوق التطبيق مع الطابعة المختارة مسبقاً. تحتاج **Epson Print Enabler** أو **Mopria Print Service** على الهاتف.

**الطريقة الثانية (تُجرَّب على الطابعة الفعلية):** الإرسال المباشر عبر **IPP** بدون أي نافذة. تُضبط من الإعدادات:
1. اكتب عنوان الطابعة: `ipp://192.168.1.50:631/ipp/print` (رقم الـ IP يُقرأ من شاشة الطابعة: الإعدادات ← الشبكة).
2. اضغط «فحص الاتصال».
3. إن نجحت، غيّر «طريقة الإرسال» إلى «مباشرة للطابعة».

إذا فشلت الطباعة المباشرة لأي سبب، يرجع التطبيق تلقائياً إلى الطريقة الأولى.

**النسخ**: تُختار ككبسولات (البائع / المشتري / المعرض). الافتراضي للعقد ثلاث نسخ وللوصل نسختان، ويُطبع فوق كل نسخة اسم صاحبها. كل النسخ تُطبع بضغطة واحدة.

**المشاركة**: زر «مشاركة» يُخرج نسخة PDF ترسل للزبون عبر واتساب.

## ما زال مطلوباً من المعرض

1. **صور العقد بجودة عالية** — الشعار، صورة الترتكتر، صورة السيارة. تُرفع من: الإعدادات ← صور رأس العقد. (حالياً مكانها مربعات فارغة منقّطة.)
2. **صورة الوصل الورقي الحالي** لتثبيت حقوله وشكله النهائي.
3. **الضبط النهائي للطباعة** — تُطبع نسخة تجريبية على ورقة حقيقية، وتُقارن بالدفتر، وتُعدَّل المقاسات في `www/css/print.css` حتى التطابق التام. هذه الخطوة إلزامية ولا يمكن إنجازها إلا مع طابعة وورق حقيقيين.
4. **قرارات معلّقة**: صياغة «الآلية» أو «السيارة» في الشروط (تُعدَّل من الإعدادات ← شروط العقد)، وهل رقم المحرك إلزامي (حالياً اختياري)، وموديل طابعة Epson لتأكيد دعم IPP.
