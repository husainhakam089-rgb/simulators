# محاكي الأنسجة: الفصل الثاني، أحياء السادس العلمي

نسخة باسم **د. أحمد الحسن** (دكتوراه · كلية العلوم · جامعة بغداد · ثانوية الإمام الحسن المجتبى (ع) للمتفوقين). هي جزء ثاني من محاكي «الخلية»
(`biology-cell/`) وتستخدم نفس المحرّك والواجهة: مجسّمات WebGL مكتوبة داخل الملف بدون
مكتبات، وتنتقل تلقائياً للرسم بـ Canvas 2D إذا الجهاز ما يدعم WebGL. وفيها نفس لوحة
المعلومات ووضع الامتحان والرسم اليدوي والوضع النهاري وملء الشاشة وتخطيط الموبايل.
الملف `الفصل-الثاني-الدكتور-أحمد-الحسن.html` واحد ويشتغل بدون إنترنت.

> **المصدر:** ملزمة الدكتور أحمد الحسن للفصل الثاني (120 صفحة). التبويبات تُطابَق مع الملزمة
> تبويباً تبويباً: نصوصها ورسومها وخطوات رسمها، ورقم الصفحة يظهر تحت اسم كل جزء.
> **تمّ:** التبويبات الأربعة الأولى (الأنسجة النباتية). الباقي ما زال بنصوص المنهج لحين مطابقته (قائمة TODO بآخر قسم المحتوى).
> الرسم اليدوي صار فيه رسوم الملزمة فقط وبخطواتها (من النبات: نسيج اللحاء ص16–17).
> ترتيب التبويبات وأسماؤها صارت مثل الملزمة: المرستيمي، الأساس، البشرة، الوعائي، ثم الحيوانية.

## التبويب الخامس: النسيج الظهاري (الطلائي) — ملزمة ص26–41

الأنواع الثمانية بالملزمة، كل واحد برسم يشبه رسم الملزمة (كتلة مائلة أو مقطع) على الغشاء القاعدي وتحته نسيج ضام، وبحركة توضّح وظيفته اللي تذكرها الملزمة:

| الشاشة | الرسم والحركة | الأجزاء القابلة للضغط |
|---|---|---|
| حرشفي بسيط (ص28–29) | صفيحة خلايا مضلعة بنوى مسطحة؛ جزيئات تعبر الطبقة الرقيقة = الانتشار والترشيح | خلية حرشفية، النواة، الغشاء القاعدي، نسيج ضام |
| مكعبي بسيط (ص28–29) | قوس من خلايا مكعبة بنوى كروية؛ إفراز وامتصاص | خلية مكعبة، النواة، الغشاء القاعدي، نسيج ضام |
| عمودي بسيط (ص30–31) | أعمدة طويلة بنوى بيضوية قرب القاعدة وأهداب؛ إفراز وامتصاص | أهداب، خلية عمودية، النواة، الغشاء القاعدي، نسيج ضام |
| عمودي مطبق كاذب (ص30–31) | خلايا قصيرة وطويلة كلها على الغشاء القاعدي وأنويتها بمستويات مختلفة؛ الأهداب تدفع الإفرازات = الحماية والإفراز | نفسها |
| حرشفي مطبق (ص32–33) | الطبقات واضحة بأسمائها جنب الكتلة، والعرض يمشي عليها طبقة طبقة (السطحية الحرشفية ← الوسطى متعددة السطوح ← القاعدية المكعبة أو العمودية) وبعدها الوظيفة: أجسام تصطدم بالسطح وترتد = الحماية | خلية حرشفية، خلايا متعددة السطوح، خلية مكعبة عمودية، الغشاء القاعدي، نسيج ضام |
| مكعبي مطبق (ص32–33) | صفّا مكعبات وسطح بقباب؛ الحماية والإفراز | خلية مكعبة، الغشاء القاعدي، نسيج ضام |
| عمودي مطبق (ص34–35) | صف خلايا عمودية فوق صف أصغر متعدد السطوح؛ الحماية | خلية عمودية، خلايا متعددة السطوح، النواة، الغشاء القاعدي، نسيج ضام |
| متحول (ص34 وص36) | خلايا مظلية بنواة أو نواتين فوق متعددة السطوح فوق مكعبة؛ النسيج يتمدد ويتسطح وبعدين يرجع (المثانة) | الخلايا المظلية، النواة، متعددة السطوح، خلية مكعبة، الغشاء القاعدي، نسيج ضام |
| بسيط × مطبق (ص27 وص32) | صف واحد جنب أكثر من صف | البسيط، المطبق، الغشاء القاعدي |

الرسم اليدوي للأنواع السبعة المرسومة بالملزمة يمشي بخطوات الملزمة نفسها (ص29: خمس خطوات للحرشفي والمكعبي البسيط؛
ص31 وص33 وص35: ثلاث خطوات لكل نوع) وبتأشيراتها. المتحول ما إله رسم بالملزمة فما داخل بالرسم اليدوي ولا برسوم الامتحان.
الجداول: البسيط بأنواعه (ص28 وص30)، والمطبق بطبقاته (ص32 وص34). الأسئلة من أسئلة الملزمة (أين يوجد، علل، املأ الفراغ).
انشال الوعاء الشعري تحت النسيج ومثال الحويصلة الهوائية/الأمعاء كتعليق ثابت ومراحل تجدد المطبق، لأن الملزمة ما تذكرها.

|---|---|---|
| الضام الأصيل | ينشدّ فتستقيم الألياف الكولاجينية، ويرجع لشكله بفضل الألياف المرنة | الألياف الكولاجينية، الألياف المرنة، الخلايا الليفية، المادة بين الخلوية |

| العظم | جهاز هافرس مقطوع: الدم يجري بقناة هافرس، والغذاء يطلع للخلايا عبر القنيوات | قناة هافرس، الصفائح العظمية، الفجوة، الخلايا العظمية، القنيوات |

| قارن | الأنواع الأربعة جنب بعض مع جدول الفروقات | الضام الأصيل، الغضروف، العظم، الدم |
