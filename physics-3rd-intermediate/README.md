# مختبر الفيزياء الافتراضي — الصف الثالث المتوسط

محاكي تجارب تفاعلي بملف **HTML واحد** يعمل بالنقر المزدوج، بلا إنترنت وبلا خادم،
بالعربية RTL، مصمَّم للعرض على شاشة لمس داخل الصف.

| | |
|---|---|
| الملف | `index.html` |
| المنهج | الفيزياء — الثالث المتوسط (العراق): الكهربائية الساكنة والتيار الكهربائي |
| التنقّل | ترحيب ← اختيار الفصل ← تبويبات أنشطة الفصل ← رجوع |
| الكانفاس | 900 × 480 وحدة منطقية (يُصيَّر بكثافة الجهاز فيبقى النص حادًّا) |
| الاعتمادات | لا شيء — لا CSS ولا JS خارجي ولا خطوط من الإنترنت |
| الهوية | مرحة نهارية: ألوان زاهية وحوافّ دائرية وفقاعات تطفو، ولكل نشاط لونه |

## الهوية البصرية

الوضع الافتراضي **نهاري مرح**: خلفية فاتحة، وست ألوان تتناوب على الأنشطة
(شمسي، سماوي، نعناعي، مرجاني، بنفسجي، أخضر)، وحوافّ دائرية كبيرة، وأزرار
تنبض قليلًا عند اللمس. ولكل فصل لونه وأيقونته في شاشة الاختيار.

وزر 🌙 في الهيدر ينقل إلى **وضع ليلي** بالألوان نفسها على خلفية نيلية — مفيد
حين تُطفأ أنوار الصف أو يكون العارض ضعيف الإضاءة.

الحركات كلها `transform` فقط (خفيفة على معالج شاشة الصف)، وتتوقف تلقائيًا لمن
يفعّل `prefers-reduced-motion` في جهازه.

## الأنشطة

فصلا المنهج العراقي الأولان لمادة الفيزياء في الصف الثالث المتوسط.

**الفصل الأول — الكهربائية الساكنة**

| # | النشاط | المشهد | العلاقة المطبَّقة |
|---|--------|--------|------------------|
| ١ | الشحنة وتركيب الذرة | ذرة بنواة وإلكترونات تدور | `q = n × 1.6×10⁻¹⁹ C` |
| ٢ | طرائق شحن الأجسام | مسطرة وصوف، كرة معدنية، قضيب مشحون | حفظ الشحنة في الدلك واللمس والحث |
| ٣ | الكشاف الكهربائي | كشاف بورقتَي ذهب داخل وعاء زجاجي | زاوية الانفراج تتبع الشحنة المؤثرة |
| ٤ | قانون كولوم | شحنتان وسهما القوة ومنحني `F` مع `r` | `F = k·q₁·q₂/r²` |
| ٥ | المجال الكهربائي | خطوط مجال وشحنة اختبار | `E = k·Q/d²` |
| ٦ | مانعة الصواعق | سحابة وبناية وتفريغ كهربائي | الحثّ وتجمّع الشحنة عند الأطراف المدبّبة |

**الفصل الثاني — التيار الكهربائي**

| # | النشاط | المشهد | العلاقة المطبَّقة |
|---|--------|--------|------------------|
| ١ | التيار وشدته | دائرة فيها أميتر وإلكترونات تسري | `I = Q/t` |
| ٢ | القوة الدافعة وفرق الجهد | فولتميتر وسلّم جهد | `ε = W/q` |
| ٣ | المقاومة وقانون أوم | دائرة بمقاومة ومنحني `V` مع `I` | `V = I·R` |
| ٤ | ربط المقاومات | مقاومتان توالٍ وتوازٍ | `R = R₁+R₂` و `R = R₁R₂/(R₁+R₂)` |
| ٥ | القدرة والطاقة | خمسة أجهزة بيتية ومقارنة استهلاكها | `P = V·I` و `E = P·t` |
| ٦ | الدائرة والمصهر | دائرة بيت ومصهر ينصهر عند تجاوز الحدّ | `I(total)` مقابل تقدير المصهر |

### التحكم باليد

في الأنشطة التي للموضع فيها معنى، يمسك الطالب الجسم **بإصبعه على الرسم** ويحرّكه:

| النشاط | ما تسحبه | ما يتغيّر |
|---|---|---|
| الكشاف الكهربائي | القضيب المشحون | بعده عن القرص وزاوية الانفراج |
| قانون كولوم | الشحنة اليمنى | البعد `r` والقوة `F` |
| المجال الكهربائي | شحنة الاختبار | البعد `d` وشدة المجال `E` |

هالة متقطّعة حول الجسم تقول للطالب إنه يستطيع مسكه، والمنزلق المقابل يتبع
السحب لحظة بلحظة فيبقى الرقم والرسم متطابقين (`setControlSnap`).

وزر **تلقائي/يدوي** في كل نشاط يوقف الحركة، ليقرأ الطالب القيم بهدوء ويسجّلها.

### بنية كل نشاط

كل نشاط مبنيّ على ترتيب نشاطات الكتاب نفسه:

1. **الغرض من النشاط** — جملة واحدة تقول للطالب ما الذي سيتعلّمه.
2. **المواد والأدوات** — أدوات حقيقية يعرفها (شريط قياس، ساعة توقيت، ميزان نابضي).
3. **خطوات العمل** — ست خطوات مرقّمة بصيغة الأمر.
4. **جدول تسجيل النتائج** — يضبط الطالب القيم ثم يضغط «سجّل القراءة الحالية»
   فيُضاف صف بالقيم المحسوبة، حتى ثماني قراءات، ولكل نشاط جدوله المحفوظ.
5. **الاستنتاج** — مخفيّ حتى يكتب الطالب استنتاجه في دفتره ثم يضغط ليقارن.
6. **سؤال النشاط** — سؤال تفكير في نهاية السايدبار.

الغرض والأعمدة والاستنتاج والسؤال كلها في `EXPERIMENTS[id]`، ودالة
`tNNReading()` في كل نشاط تُرجع صف القراءة مطابقًا لأعمدته.

كل رقم يظهر على الشاشة يُحسب من القانون وقت التشغيل — لا قيمة مكتوبة يدويًا
ولا رسم ثابت يمثّل نتيجة.

## اسم الأستاذ

**من الشاشة نفسها، بلا فتح الكود:** اضغط على «إعداد: …» في شاشة الترحيب أو في
أعلى الصفحة، اكتب اسمك، ثم «حفظ». يظهر فورًا في المواضع الثلاثة (الترحيب
والهيدر والتذييل) ويُحفظ في المتصفح فلا تعيد كتابته عند فتح الملف مرة أخرى.

إن منع المتصفح الحفظ (يحدث في بعض الإعدادات عند فتح الملف مباشرة من القرص)
يظهر الاسم في هذه الجلسة مع تنبيه صريح بأنه سيعود إلى الافتراضي بعد الإغلاق.

وإن أردت تثبيت الاسم داخل الملف قبل توزيعه على الطلاب، غيّر السطر:

```js
const TEACHER = 'اسم الاستاذ';
```

فهو القيمة الافتراضية التي تظهر لمن لم يحفظ اسمًا بعد.

## إضافة تجربة جديدة

أربع خطوات، عند العلامات المكتوبة داخل الملف:

1. **وحدة النشاط** عند `<!-- ==== INSERT: ACTIVITY SCRIPTS ==== -->`:

   ```js
   (function(){
     const COLORS = makeColors();
     const state = { simMode:'auto', t:0, /* متغيرات التجربة */ };
     function t12Update(dt){ if(state.simMode==='auto') state.t += dt; }
     function t12Draw(){ /* رسم فقط، بلا تعديل حالة */ }
     window.t12State=state; window.t12Update=t12Update; window.t12Draw=t12Draw;
   })();
   ```

2. **لوحة التحكم** عند `<!-- ==== INSERT: CONTROL PANELS ==== -->` بـ `data-tab="12"`،
   والمنزلقات تُربط بـ `data-target="t12State.x"` و `data-label`.
3. **بطاقة النشاط** في `EXPERIMENTS[12]` (عنوان، وصف، أدوات، خطوات، وسؤال النشاط).
4. **رقم التجربة** في `CHAPTERS[1].tabs`.

الترقيم: `11، 12…` للفصل الأول و `21، 22…` للثاني — لا يتضارب، ودوال كل تجربة
تحمل الرقم نفسه (`t12Draw` / `t12Update` / `t12State`).

## رسوم الأدوات

كلها من عناصر الكانفاس الأساسية بلا أي صورة خارجية، ومرسومة لتشبه ما يراه
الطالب في المختبر: `figAtom` و `figChargedBall` و `figRod` و `figElectroscope`
و `figBattery` و `figBulb` و `figResistor` (بأشرطتها الملوّنة) و `figMeter`
(بقرص وإبرة) و `figSwitch` و `figFuse` و `figCloud` و `figBuilding` و `figSpark`
و `figSign` و `figPerson`.

للواقعية: `sphereFill` تعطي الكرات تدرّجًا كرويًا، و `tubeFill` تعطي الأجسام
الأسطوانية لمعتها، و `groundShadow` تثبّت الجسم على الأرض بظلّ بيضوي،
و `glassShine` تضيف لمعة الزجاج. ودالة `sci` تكتب الأرقام الكبيرة بصيغة
`1.8×10⁶` بدل صفوف الأصفار.

## قواعد النصّ العربي على الكانفاس

هذه القواعد سبب معظم أخطاء العرض، فالتزم بها:

1. لا `ctx.fillText` مباشرة — استعمل `optLabel` / `optHUD` / `optTitle` / `optCaption`.
2. أي سطر فيه معادلة أو رقم لاتيني يُعلَّم `ltr:true`، وإلا قلب المتصفح ترتيبه.
3. لا تبدأ سطرًا عربيًا برقم أو رمز لاتيني.
4. اكتب المعادلات مضغوطة: `a = F/m` لا `a = F / m` داخل نص عربي.
5. الوحدات داخل الجملة العربية بالعربية (متر، ثانية)، وباللاتينية داخل سطر `ltr:true`.
6. **تجنّب الشدّة مع التنوين** (`ـًّا`) في نصوص الكانفاس: اكتب «خطيًا» لا «خطيًّا» —
   بعض الخطوط تعرضها مربّعًا فارغًا.
7. **لا تضع حرفًا عربيًا داخل سطر معلَّم `ltr:true`**: `F(أ→ب)` تخرج مبعثرة،
   فاستعمل `F(A→B)` في المعادلات و«الطالب A» في النصّ العربي.
8. كل رسم متحرك يمتد يحتاج `ctx.save(); ctx.clip(); … ctx.restore()`، وتأكّد أن
   مستطيل الـ clip يشمل الجسم فعلًا (خطأ وقعنا فيه: الجسم اختفى لأنه خارج الـ clip).

## الاختبار

```bash
npm install jsdom canvas playwright   # مرة واحدة
node tests/run-tests.js               # اختبار وظيفي + تصيير كل التجارب
node tests/browser-shots.js           # فحص التخطيط في متصفح حقيقي
```

كلاهما يجب أن ينتهي بـ **صفر أخطاء**.

السكربت ينتقل بين الفصلين وكل أنشطتهما، ويضغط كل زر مرتين، ويحرّك كل منزلق إلى
أربع قيم (الأدنى، ٣٧٪، المنتصف، الأقصى)، ويتحقق من امتلاء السايدبار ومن أن القيم
المعروضة ليست `NaN`، ويبدّل المظهر الفاتح، ويتأكد أن حلقة الرسم تتوقف خارج شاشة
الأنشطة وأن حالة كل نشاط لا تُفقد عند الرجوع.

ويتحقق أيضًا من أن **قيمة كل منزلق عند الفتح تطابق قيمة الحالة التي يتحكم بها**
وأنها داخل مداه — بدون هذا الفحص يعرض الرسم قيمة ويعرض المنزلق قيمة أخرى حتى
أول لمسة (وقعنا في هذا في ثلاثة أنشطة).

ويتحقق من **اكتمال بنية كل نشاط**: وجود الغرض والاستنتاج والسؤال، وأن عدد قيم
`tNNReading()` يساوي عدد أعمدة الجدول تمامًا، وأن تسجيل قراءتين يضيف صفين وأن
زر المسح يفرغ الجدول وأن الاستنتاج يبقى مخفيًا حتى يُضغط.

كما يصيّر كل تجربة إلى PNG بأبعاد 900×480 في `tests/shots/` — بالحالة الافتراضية،
وبعد كل زر تبديل، وعند القيمة القصوى لكل منزلق. **افحص هذه الصور بالعين**؛ التداخل
بين النصوص وانقلاب المعادلات وخروج الرسم عن الإطار لا يظهر أيٌّ منها في اختبار jsdom.

أما `tests/browser-shots.js` فيفتح الملف في Chromium بمقاس شاشة الصف (1366×768)
وبمقاس جوال (412×915)، ويلتقط شاشة الترحيب واختيار الفصل والتجارب، ويتحقق من أن
أهداف اللمس كبيرة بما يكفي للإصبع وأن الصفحة لا تنزلق أفقيًا. اللقطات في
`tests/browser/`.
