# الفصل الثالث — التيار الكهربائي (مفصول مؤقتًا)

هذا الفصل **مرفوع من الملف الرئيسي** ومحفوظ هنا ملفًا قائمًا بذاته، تمهيدًا
لدمجه لاحقًا مع الفصل الرابع في ملف واحد.

`index.html` في هذا المجلد يعمل وحده: افتحه بالنقر المزدوج بلا إنترنت،
وفيه الأنشطة الستة كاملة بلوحات تحكمها وجداول نتائجها وأسئلتها.

| # | النشاط | العلاقة المطبَّقة |
|---|--------|------------------|
| ١ | التيار الكهربائي وشدته | `I = Q/t` |
| ٢ | القوة الدافعة وفرق الجهد | `ε = W/q` |
| ٣ | المقاومة وقانون أوم | `V = I·R` |
| ٤ | ربط المقاومات | `R = R₁+R₂` و `R = R₁R₂/(R₁+R₂)` |
| ٥ | القدرة والطاقة | `P = V·I` و `E = P·t` |
| ٦ | الدائرة والمصهر | `I(total)` مقابل تقدير المصهر |

معرّفات الأنشطة هنا **21 إلى 26**، وهي محجوزة لها ولم تُستعمل في الملف
الرئيسي، فلا يقع تضارب عند الدمج.

## كيف يُدمج مع الفصل الرابع لاحقًا

الملفان (هذا والرئيسي) بنيتهما واحدة، فالدمج نقل أربع قطع لا أكثر:

1. **كتل الأنشطة**: كل نشاط كتلة `<script>` مستقلة تنتهي بسطر
   `window.tNNState = state; window.tNNUpdate = ...; window.tNNDraw = ...;`
   تُنقل كما هي.
2. **لوحات التحكم**: `<div class="control-panel" data-tab="NN">` لكل نشاط.
3. **بيانات الأنشطة**: عنصر `NN: { purpose, cols, conclusion, question,
   title, subtitle, tools, steps }` داخل `EXPERIMENTS`.
4. **ربط الأزرار**: أسطر `bindGroup('#...NN', 'data-...NN', ...)`.

ثم يُضاف الفصل إلى `CHAPTERS` بترتيبه ومعرّفات أنشطته في `tabs`.

وأنشطة هذا الفصل تستعمل من الأدوات المشتركة: `wire` و`flowDots` و`figBattery`
و`figBulb` و`figResistor` و`figMeter` و`figFuse` و`circuitSwitch`
و`switchTap` — وكلها موجودة في الملف الرئيسي أيضًا.

## الفحص

أدوات الفحص الثلاث تقبل هذا الملف عبر متغيّر البيئة `PHYS_HTML`:

```
PHYS_HTML=$PWD/chapters/electric-current/index.html node tests/run-tests.js
PHYS_HTML=$PWD/chapters/electric-current/index.html node tests/audit.js
PHYS_HTML=$PWD/chapters/electric-current/index.html node tests/browser-shots.js
```

آخر نتيجة: jsdom صفر أخطاء، والفحص واحدًا واحدًا ٦ من ٦ بلا ملاحظات،
وكروم بلا أخطاء.
