# الخلية — محاكي تفاعلي (أحياء السادس الإعدادي · الفصل الأول)

محاكي تعليمي تفاعلي للفصل الأول «الخلية» من مادة الأحياء للسادس الإعدادي
العلمي (المنهج العراقي). بدل الرسومات الثابتة، الطالب يشوف الخلية حيّة
تتحرك، وكل عضية تؤدي وظيفتها على الشاشة، وعند الضغط على أي جزء تظهر
معلوماته كاملة.

## التشغيل

افتح `index.html` مباشرة بأي متصفح حديث — لا يحتاج إنترنت ولا خادماً ولا
أي ملف خارجي. يشتغل offline تماماً على الموبايل واللابتوب.

## الأقسام

| التبويب | المحتوى |
|---|---|
| الخلية الحيوانية | خلية كاملة بحركة جريان السايتوبلازم: رسائل RNA تخرج من الثقوب النووية نحو الرايبوسومات، بروتين يمشي في قنوات الشبكة الخشنة إلى جهاز كولجي، حويصلات إفرازية تخرج عبر الغشاء، جسيم حال يلتحم بجسم غريب ويهضمه، ومايتوكوندريا تنبض وتوزّع الطاقة |
| الخلية النباتية | الجدار الخلوي، الفجوة العصارية الكبيرة، البلاستيدات الخضراء تلمع مع دخول الضوء، وزر «قارن بالحيوانية» يبرز الفروقات مع جدول |
| بدائية النواة وحقيقية النواة | خلية بكتيرية بجانب خلية حقيقية النواة مع إبراز الفروقات وجدولها |
| الغشاء البلازمي مكبّراً | مقطع مكبّر بالطبقة الدهنية المزدوجة والبروتينات، مع اختيار جزيئة ومشاهدة هل تعبر أو ترتد (النفاذية الاختيارية) |
| النواة مكبّرة | الغلاف النووي وثقوبه، البلازم النووي، النوية، الشبكة الكروماتينية |
| الانقسام الخيطي | شريط أطوار + تشغيل، اسم الطور ووصفه وعدد الكروموسومات يتحدثون تلقائياً، وتبديل بين الخلية الحيوانية والنباتية |
| الانقسام الاختزالي | الانقسامان الأول والثاني مع إبراز التصالب (العبور) وعدّاد الكروموسومات حتى الخلايا الأربع (n) |
| وضع الامتحان | «أشّر الأجزاء»: رسم بلا أسماء وسحب الأسماء إلى مواضعها مع عدّاد درجة · «اختبر نفسك»: أسئلة اختيار من متعدد مع شرح الجواب بعد كل سؤال |

## أدوات التحكم

تشغيل/إيقاف الحركة · سرعة الحركة · إظهار/إخفاء الأسماء على الرسم ·
تأثيرات واقعية (تدرجات وتوهّج) · إعادة المشهد. وعند الضغط على أي عضية:
تتكبّر وتلمع ويخفت الباقي، وتظهر لوحة فيها الاسم والموقع والتركيب
والوظيفة وملاحظة مهمة للامتحان، مع زر «شوف الوظيفة» يعيد حركة تلك العضية
لوحدها وبشكل أبطأ.

## البنية التقنية

- ملف واحد `index.html` فيه HTML + CSS + JavaScript، بلا أي مكتبة خارجية.
- الرسم كله SVG مولّد بالكود (تدرجات لونية، ظلال ناعمة، نسيج، توهّج)،
  وطبقة Canvas لجريان السايتوبلازم.
- واجهة عربية كاملة `dir="rtl"` بخط النظام مع بدائل (Tahoma / Segoe UI).
- يعمل على شاشة بعرض 380px بلا تمرير أفقي، واللمس يعمل مثل الضغط والسحب.
- يحترم `prefers-reduced-motion`.
- الواجهة مطابقة لمحاكي `dragon-war` في المستودع: اللوحات والألوان
  وترتيب الأزرار نفسها.

## ⚠ المصدر العلمي وقائمة TODO

الملزمة (PDF أو صور الفصل الأول) **لم تكن موجودة في الفولدر** وقت بناء
المحاكي، فبُنيت كل المشاهد والنصوص بمصطلحات المنهج العراقي المثبّتة في
طلب العمل: «الشبكة البلازمية الداخلية»، «الجسيمات الحالة»، «النوية»،
«الشبكة الكروماتينية»، «الغلاف النووي»، «البلازم النووي»، «السايتوبلازم».

قائمة كاملة بما يحتاج مطابقة مع الملزمة موجودة **بآخر `index.html`**
داخل تعليق HTML — أهمها: جرد رسومات الملزمة صفحة صفحة، الصياغة الحرفية
للتعاريف، مواضع التأشيرات، جداول المقارنة، الأسئلة الوزارية، وهل
الانقسام الخلوي أصلاً ضمن الفصل الأول أم لا.

المحتوى كله مجموع في أعلى ملف الـ JavaScript داخل `INFO` و `TABLES` و
`QUIZ`، فاستبدال النصوص بنصّ الملزمة لا يحتاج لمس بقية الكود.
