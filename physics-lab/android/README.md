# PhysicsLab.apk — تطبيق أندرويد

تطبيق أندرويد (‎410 كيلوبايت) يحمل المحاكي وصورة الواجهة داخله. يعمل بلا
إنترنت، و**بلا أي صلاحيات إطلاقًا** — لا كاميرا ولا ملفات ولا حتى صلاحية
الإنترنت، لأن كل شيء داخل التطبيق.

## التنصيب على الهاتف

انقل `PhysicsLab.apk` إلى الهاتف وافتحه. أندرويد سيطلب السماح بالتنصيب من
مصدر غير المتجر (**تنصيب تطبيقات غير معروفة**) — اسمح لمرّة واحدة للتطبيق الذي
تفتح منه الملف (المتصفّح أو مدير الملفات)، ثم اضغط «تنصيب».

## المواصفات

| | |
|---|---|
| اسم الحزمة | `iq.alaboudi.physicslab` |
| أقلّ إصدار | أندرويد ٥ (API 21) |
| الإصدار المستهدف | API 33 |
| الصلاحيات | لا شيء |
| التوقيع | v1 + v2 + v3 |
| الاتجاه | يدور مع الهاتف (طولي وعرضي) |

## البنية

نشاط واحد (`MainActivity`) يعرض `assets/index.html` في `WebView` بملء الشاشة:

- جافاسكربت وتخزين المتصفّح مفعّلان (المحاكي كلّه جافاسكربت، ويحفظ تفضيل
  المظهر والصوت).
- `configChanges` تمنع إعادة إنشاء النشاط عند تدوير الهاتف، فلا تُفقد التجربة
  المفتوحة ولا يُعاد تحميل الصفحة.
- **زرّ الرجوع** ينزل مستوًى واحدًا داخل المحاكي بدل الخروج فورًا: من تجارب
  الفصل إلى قائمة الفصول، ومن قائمة الفصول يخرج من التطبيق.
- تسريع العتاد مفعّل، فرسوم الـ canvas في التجارب تعمل بسلاسة.

## إعادة البناء

بعد أي تعديل على `../index.html`:

```bash
sudo apt-get install -y aapt apksigner zipalign dalvik-exchange \
                        android-sdk-platform-23 default-jdk
./build.sh
```

بلا Gradle وبلا تنزيل أي شيء من جوجل — كل الأدوات من مستودعات دبيان/أوبنتو.
`build.sh` يصرّف الجافا، ويحوّلها إلى dex، ويحزم المانيفست والموارد والأصول
بـ `aapt`، ثم يحاذي ويوقّع.

## مفتاح التوقيع

`physicslab.keystore` مفتاح توقيع ذاتي للاستعمال المدرسي، كلمة سرّه
`physicslab` وهي مكتوبة داخل `build.sh` — فهو **ليس سرًّا**، ولا يحمي شيئًا
ذا قيمة ما دام التطبيق لا يُنشر في متجر.

احتفظ به مع المشروع: أندرويد يرفض تحديث تطبيق مثبَّت إن اختلف توقيعه، فلو
بُني بمفتاح جديد لاحتاج الطلاب إلى حذف النسخة القديمة أوّلًا. ولو أردت نشر
التطبيق في متجر يومًا، فولّد مفتاحًا جديدًا واحفظه خارج المستودع.
