# صورة الواجهة

`welcome.jpg` هنا هي صورة الواجهة بعد مسح شريط Account / Simulations / About
منها. وهي **مدمجة داخل `index.html`** كـ base64، فالملف يحمل صورته معه إلى أي
جهاز ولا يحتاج هذا المجلّد إطلاقًا. المجلّد محفوظ للرجوع والتعديل فقط.

## تبديل الصورة

بدّل قيمة `WELCOME_ART.background` في `index.html` (مسار ملف أو data URI).

## الإعدادات في `index.html` (داخل `WELCOME_ART`)

| المفتاح | المعنى | القيمة الحالية |
|---|---|---|
| `background` | الصورة نفسها (base64 أو مسار) | الصورة المدمجة |
| `cropTop` | نسبة القصّ من أعلى الصورة | `0` (الشريط ممسوح أصلًا) |
| `buttonOnArt` | الزرّ مرسوم داخل الصورة | `true` |
| `buttonX` / `buttonY` | مركز الزرّ المرسوم (نسبة من العرض/الارتفاع) | `0.514` / `0.887` |
| `buttonW` / `buttonH` | مقاس مساحة الضغط | `0.345` / `0.165` |

`buttonOnArt: true` يعني أن الزر الحقيقي يوضع **شفّافًا** فوق الزرّ المرسوم في
الصورة، فما يراه المستخدم هو البوستر نفسه وهو يعمل. اجعلها `false` لو كانت
صورتك بلا زرّ مرسوم، فيُرسم زرّ ذهبي حقيقي بدلًا من ذلك.
