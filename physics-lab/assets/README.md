# ملفات الواجهة

ضع هنا صورة الواجهة الترحيبية باسم `welcome.jpg` (أو `.png`) فتظهر تلقائيًا
كخلفية شاشة الترحيب بملء الشاشة، ويبقى زر **ابدأ المحاكاة** زرًّا حقيقيًا فوقها.

- الشريط العلوي المرسوم داخل الصورة (Account / Simulations / About) يُقصّ
  تلقائيًا بمقدار `WELCOME_ART.cropTop` في `index.html` (الافتراضي `8%`).
  زِد القيمة إن بقي منه أثر، أو أنقصها إن قُصّ أكثر من اللازم.
- الزرّ المرسوم أسفل الصورة يختفي تحت تعتيم سفلي يجلس فوقه الزر الحقيقي.
- إن لم توجد الصورة يعود المحاكي تلقائيًا إلى مشهد المختبر المرسوم بالـ CSS،
  فلا تظهر شاشة فارغة أبدًا.

لو أردت صورة الأستاذ وحدها (PNG بخلفية شفافة) فوق المشهد المرسوم، سمِّها
`teacher.png` واضبط `WELCOME_ART.photo = 'assets/teacher.png'` في `index.html`.
