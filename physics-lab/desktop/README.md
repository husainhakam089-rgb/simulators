# PhysicsLab.exe — تطبيق ويندوز

ملف تنفيذي **واحد** (‎787 كيلوبايت) يحمل المحاكي وصورة الواجهة وأيقونته داخله.
لا تنصيب، ولا مجلّد ملفات، ولا إنترنت.

## التشغيل

دبل كلك على `PhysicsLab.exe`. تفتح نافذة التطبيق بالحجم الكامل بلا شريط عنوان
ولا تبويبات متصفّح — ومنها زر **ابدأ المحاكاة**.

## ما يفعله عند التشغيل

1. يكتب صفحة المحاكي في `%LOCALAPPDATA%\PhysicsLab_AlAboudi\index.html`
   (مسار ثابت حتى يبقى اسم الأستاذ محفوظًا بين التشغيلات).
2. يفتحها بمتصفّح كروميوم في وضع التطبيق `--app` بملف تعريف مستقلّ، فلا تختلط
   جلسة التطبيق بجلسة تصفّح المستخدم.
3. يبحث عن المتصفّح في `App Paths` بالسجلّ أوّلًا (الطريق الرسمي)، ثم في مسارات
   Edge و Chrome و Brave المعتادة.
4. إن لم يجد أيّها، يفتح الصفحة بالمتصفّح الافتراضي.

## المتطلّبات

ويندوز ٦٤ بت. Edge موجود أصلًا في ويندوز ١٠ و ١١ فلا حاجة لتنصيب شيء؛ ولو
أُزيل، يكفي Chrome أو Brave أو أي متصفّح افتراضي.

## إعادة البناء

بعد أي تعديل على `../index.html`:

```bash
sudo apt-get install -y mingw-w64     # مرّة واحدة
./build.sh
```

`build.sh` ينسخ `../index.html` إلى مجلّد البناء، ويدمجه مع الأيقونة ومعلومات
الإصدار في `app.res`، ثم يصرّف `launcher.c` تصريفًا متقاطعًا إلى `PhysicsLab.exe`.

## الملفات

| الملف | الدور |
|---|---|
| `launcher.c` | المشغّل: استخراج الصفحة، ترميز العنوان، البحث عن المتصفّح، التشغيل |
| `app.rc` | يدمج `index.html` كمورد RCDATA رقم ‎101، والأيقونة، ومعلومات الإصدار |
| `app.ico` | الأيقونة (شعار mA من البوستر) بستّة مقاسات من ١٦ إلى ٢٥٦ |
| `build.sh` | أمر البناء |
