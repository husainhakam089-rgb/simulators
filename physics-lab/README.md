# مختبر الفيزياء الافتراضي — الفصلان الرابع والخامس

تطبيق واحد يجمع محاكيات الفصل الرابع (الموجات الكهرومغناطيسية) والفصل الخامس
(البصريات الفيزيائية) — الفيزياء، الصف السادس الإعدادي.

**19 تجربة تفاعلية** في ملف `index.html` واحد، بدون أي اعتماد على الإنترنت
(عدا خطوط Google الاختيارية) وبدون خطوة بناء: افتح الملف في المتصفح فقط.

## الاستعمال

افتح `index.html` في أي متصفح حديث. شاشة البداية تعرض الفصلين — اختر أحدهما،
ويمكن التنقّل بينهما لاحقًا من **شريط الفصول** أعلى التطبيق. شريط التبويبات
تحته يعرض تجارب الفصل المختار.

لكل تجربة: شريط أدوات وخطوات جانبي، لوحة تحكم بمنزلقات وأزرار، وضع **تلقائي**
(حركة مستمرة) أو **يدوي** (تجميد المشهد للتفحّص)، ملء شاشة، مظهر فاتح/داكن،
وكتم الصوت. التطبيق يعمل باللمس على الأجهزة اللوحية والسبورات التفاعلية.

## البنية الداخلية

الملفان الأصليان كانا يتقاسمان نفس الهيكل بالكامل (نفس CSS ونفس منطق اللوحة
والمؤشر والصوت والمظهر وملء الشاشة)، وكانت كل تجربة فيهما دالة مغلقة (IIFE)
تنشر حالتها ودوالها باسم `window.tN*`. لذلك تمّ الدمج بإعادة تسمية النطاقات
لا بإعادة كتابة المحاكيات:

- تجارب الفصل الرابع أصبحت `em1` … `em11`، وتجارب الفصل الخامس `op1` … `op8`.
- مفتاح التبويب صار نصًّا مثل `em3` / `op7`، وحلقة الرسم تستدعي
  `window[key+'Update']` و`window[key+'Draw']` مباشرة بدل جملة `switch`.
- معرّفات عناصر لوحات التحكم أخذت بادئة الفصل (`em-` / `op-`) لمنع أي تعارض
  (`val-speed1` مثلًا كان موجودًا في الفصلين معًا).
- الهيكل المشترك (اللوحة، المؤشر، الصوت، المظهر، ملء الشاشة) صار نسخة واحدة،
  ودوال الرسم المساعدة المشتركة كذلك.

كود المحاكاة والرسم نفسه منقول حرفيًّا من الملفين الأصليين دون تعديل.
