# مختبر الفيزياء الافتراضي — الصف الثالث المتوسط

محاكي أنشطة فيزياء تفاعلي يعمل بالكامل داخل المتصفح في ملف واحد
(`index.html`) بلا خادم وبلا أي مكتبات أو خطوط خارجية.

## التشغيل

**على ويندوز:** دبل كلك على `desktop/PhysicsLab.exe` — ملف تنفيذي واحد يحمل
المحاكي داخله، بلا تنصيب ولا إنترنت. التفاصيل في `desktop/README.md`.

**بأي نظام:** افتح `index.html` مباشرة بالمتصفح، أو شغّل خادم ملفات ثابتة:

```bash
python3 -m http.server --directory physics-lab 8080
```

## واجهة الترحيب

أول ما تُفتح الصفحة تظهر واجهة ترحيبية بملء الشاشة بلا أي شريط علوي،
وفيها زر **Begin Simulation / ابدأ المحاكاة** حقيقي ينقلك إلى شاشة اختيار
الفصل (يعمل بالنقر وبمفتاح Enter أو المسافة).

صورة الواجهة مدمجة داخل `index.html` نفسه، فالملف الواحد يكفي: انسخه لأي
جهاز وتظهر الواجهة معه بلا أي ملف خارجي. تفاصيل تبديلها وضبطها في
`assets/README.md`.

## اسم الأستاذ

يُعدَّل من الكود فقط: غيّر `TEACHER` و `TEACHER_EN` في أعلى سكربت `index.html`
فيتغيّر الاسم في شاشة الترحيب وأعلى الصفحة وأسفلها. لا يوجد زر تعديل ولا حفظ
في المتصفّح. (الاسم مرسوم أيضًا داخل صورة الواجهة، فبدّلها معه إن غيّرته.)

بعد أي تعديل، أعد بناء تطبيق ويندوز بـ `desktop/build.sh`.
