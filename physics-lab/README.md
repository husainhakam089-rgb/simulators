# مختبر الفيزياء الافتراضي — الصف الثالث المتوسط

محاكي أنشطة فيزياء تفاعلي يعمل بالكامل داخل المتصفح في ملف واحد
(`index.html`) بلا خادم وبلا أي مكتبات أو خطوط خارجية.

## التشغيل

افتح `index.html` مباشرة بالمتصفح، أو شغّل خادم ملفات ثابتة:

```bash
python3 -m http.server --directory physics-lab 8080
```

## واجهة الترحيب

أول ما تُفتح الصفحة تظهر واجهة ترحيبية بملء الشاشة بلا أي شريط علوي،
وفيها زر **Begin Simulation / ابدأ المحاكاة** حقيقي ينقلك إلى شاشة اختيار
الفصل (يعمل بالنقر وبمفتاح Enter أو المسافة).

صورة الواجهة مدمجة داخل `index.html` نفسه، فالملف الواحد يكفي: انسخه لأي
جهاز وتظهر الواجهة معه بلا أي ملف خارجي. تفاصيل تبديلها وضبطها في
`assets/README.md`.

اسم الأستاذ قابل للتعديل من الزر أسفل الواجهة ويُحفظ في المتصفح.
