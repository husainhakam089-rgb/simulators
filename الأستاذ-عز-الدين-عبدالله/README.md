# محاكي الأنسجة — نسخة الأستاذ عز الدين عبدالله

نفس محاكي «الأنسجة» (الفصل الثاني — أحياء السادس العلمي) الموجود في
`الدكتور-أحمد-الحسن/` بكل ما فيه: التبويبات الثمانية، الرسوم والمجسّمات الثلاثية
الأبعاد، الجداول، وضع الامتحان، والرسم اليدوي. الفرق فقط في الاسم:

- **واجهة البداية:** نفس اللوحة النيلية بالإطار الذهبي ورسمة الخلايا، و«إعداد
  الأستاذ عز الدين عبدالله».
- **داخل المحاكي:** اسم الأستاذ في أعلى الشاشة وفي عنوان الصفحة.

ملف واحد `الفصل-الثاني-الأستاذ-عز-الدين-عبدالله.html` يعمل بلا إنترنت. المحتوى العلمي وأرقام
الصفحات المذكورة في المحاكي من ملزمة الفصل الثاني نفسها المستعملة في نسخة الدكتور أحمد الحسن.
تُبنى من نسخة الدكتور أحمد بـ `tools/packaging/make_izz_ch2.py`.

## تطبيقا أندرويد وويندوز (`apps/`)

- **`apps/الفصل-الثاني-الأستاذ-عز-الدين-عبدالله.apk` (أندرويد 5 فما فوق):** تطبيق باسم «الأنسجة»
  وأيقونة الأنسجة، معرّفه `com.izzaldeen.tissues` ومفتاح توقيعه خاص بهذه النسخة،
  فيتنصّب جنب نسخ الأساتذة الآخرين بدون تعارض.
- **`apps/الفصل-الثاني-الأستاذ-عز-الدين-عبدالله.exe` (ويندوز 10 و11):** يفتح المحاكي بنافذة مستقلة
  عبر Edge (أو Chrome)، بلا إنترنت، ويحفظ ملفه في مجلد خاص `AlAnsijaIzzAlDin`.
