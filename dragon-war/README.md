# حرب التنانين — من عيون الفارس (Dragon War)

محاكي/لعبة طيران تنانين ثلاثية الأبعاد تعمل بالكامل داخل المتصفح — بلا خادم
خلفي وبلا أي ملفات خارجية إلزامية (كل التضاريس والخرائط والصوت والموسيقى
مولّدة إجرائياً بالكود). مبنية على [Three.js](https://threejs.org/).

## التشغيل

افتح `index.html` مباشرة بمتصفح حديث (Chrome/Edge/Firefox)، أو شغّل خادم
ملفات ثابتة محلي بسبب `type="module"`:

```bash
npx serve dragon-war
# أو
python3 -m http.server --directory dragon-war 8080
```

## التحكم

| المفتاح | الفعل |
|---|---|
| الماوس | توجيه رأس التنين |
| مسافة | نفث النار |
| F | عضّة قاتلة عن قرب |
| W / S | تسريع / تبطيء |
| A / D | انعطاف |
| H | تبديل قبل/بعد التدرّج السينمائي |
| P | إيقاف مؤقت |
| Esc | رجوع لمشغّل التصميم |
| الموبايل | عصا يمين للتوجيه، أزرار يسار للنار/العض/السرعة |

## الميزات

- **تصميم تنين وفارس** كامل (سلالة، ألوان، هيكل، عتاد) مع معاينة حيّة،
  ودعم استيراد موديل GLB/GLTF خاص بك.
- **عالم إجرائي مفتوح**: قارة وجزر وجدار جليدي وقلاع ومدن، دورة نهار/ليل،
  طقس ثلجي بالشمال، خط أنابيب صورة سينمائي (ACES، Bloom، GTAO، SMAA).
- **جسيمات وإضاءة ديناميكية**: نفث نار بتوهّج حقيقي ودخان يتصاعد، أثر
  سرعة عند الانقضاض، انفجار دخان وومضة ضوء عند سقوط عدو.
- **قتال وذكاء اصطناعي**: مناورة وهروب ونَفَس نار وعضّ قريب، أعداء ينسحبون
  جريحين عند صحة حرجة، **زعيم أقوى وأضخم كل 5 موجات**، ونظام **سلاسل قتل
  (combo)** يضاعف النقاط.
- **صوت وموسيقى إجرائيان بالكامل** (Web Audio): هدير نار وفرقعة، خفقان
  أجنحة يتبع السرعة، زئير عند الإصابات القوية والموت والزعماء، رياح تتغيّر
  بالسرعة والارتفاع، ووسادة موسيقية متوترة تشتد مع تقدّم الموجات.
- **واجهة لاعب مصقولة**: إيقاف مؤقت، عدّاد سلسلة القتل، مؤشرات سهم لأقرب
  الأعداء خارج حقل الرؤية، وإعدادات صوت/حساسية ماوس/عكس المحور محفوظة محلياً.

## الحالة الحالية والخطة

1. إعداد المشروع في المستودع ✅
2. تحسين الرسوميات والبيئة (جسيمات، إضاءة، دخان، أثر سرعة) ✅
3. دمج موديل تنين/فارس ثلاثي الأبعاد مخصّص من المستخدم — لتنين اللاعب ✅
4. تطوير القتال والذكاء الاصطناعي للأعداء (هروب، زعماء، سلاسل قتل) ✅
5. نظام صوت وموسيقى إجرائي واقعي ✅
6. تلميع الواجهة وتجربة اللاعب (إيقاف مؤقت، إعدادات، مؤشرات أعداء) ✅

## موديل تنين اللاعب

تنين اللاعب الافتراضي مبني من موديل "Dragon 2.0" (المؤلف: 3DHaupt، عبر
[Sketchfab](https://sketchfab.com/3d-models/dragon-20-e2d411f38bb04a4cb36f4dfe748fda47)،
ترخيص CC-BY-NC-ND-4.0 — غير تجاري). الموديل الأصلي بلا هيكل عظمي ولا
أنيميشن؛ عولج آلياً (فصل الأجنحة عن الجسم بتحليل المكوّنات المتصلة،
واستبعاد قاعدة العرض) عشان يكتسب مفصلَي جناح (`wing_L`/`wing_R`)
تتعرّف عليهما اللعبة تلقائياً وترفرف بيهم أثناء الطيران والمعاينة.
أعداء اللعبة يستخدمون موديلاً افتراضياً آخر أبسط، غير مرتبط بهذا الترخيص.

## البنية

- `index.html` — الملف الوحيد حالياً: HTML + CSS + منطق اللعبة (Three.js عبر
  ES module من jsDelivr)، ويتضمن موديلَي GLB مضمّنين بصيغة Base64 (تنين
  الأعداء الافتراضي، وتنين اللاعب المذكور أعلاه).

## ملاحظة تقنية

كل المنطق داخل ملف واحد بحجم كبير (~22 ميجا) بسبب موديلَي التنين
ثلاثيي الأبعاد المضمّنين. عند التعديل، تأكد من فحص الصيغة (`node --check`
على السكربت المستخرج) قبل النشر — الملف كبير جداً لقراءته دفعة واحدة
بمعظم المحررات، وأي أداة `grep`/`sed` غير حذرة قد "تطبع" السطرين
الضخمين بالكامل.
