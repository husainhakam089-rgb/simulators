# حرب التنانين — من عيون الفارس (Dragon War)

محاكي/لعبة طيران تنانين ثلاثية الأبعاد تعمل بالكامل داخل المتصفح — بلا خادم
وبلا أي ملفات خارجية إلزامية (كل التضاريس والخرائط والأصوات مولّدة إجرائياً
بالكود). مبنية على [Three.js](https://threejs.org/).

## التشغيل

افتح `index.html` مباشرة بمتصفح حديث (Chrome/Edge/Firefox)، أو شغّل خادم
ملفات ثابتة محلي بسبب `type="module"`:

```bash
npx serve dragon-war
# أو
python3 -m http.server --directory dragon-war 8080
```

## التحكم

| المفتاح | الفعل |
|---|---|
| الماوس | توجيه رأس التنين |
| مسافة | نفث النار |
| F | عضّة قاتلة عن قرب |
| W / S | تسريع / تبطيء |
| A / D | انعطاف |
| H | تبديل قبل/بعد التدرّج السينمائي |
| Esc | رجوع لمشغّل التصميم |
| الموبايل | عصا يمين للتوجيه، أزرار يسار للنار/العض/السرعة |

## الحالة الحالية والخطة

اللعبة تعمل، وجاري تطويرها على مراحل نحو نسخة أكثر احترافية وواقعية:

1. إعداد المشروع في المستودع ✅
2. تحسين الرسوميات والبيئة (جسيمات، إضاءة، تفاصيل تضاريس)
3. دمج موديل تنين/فارس ثلاثي الأبعاد مخصّص من المستخدم
4. تطوير القتال والذكاء الاصطناعي للأعداء
5. نظام صوت وموسيقى إجرائي واقعي
6. تلميع الواجهة وتجربة اللاعب

## البنية
