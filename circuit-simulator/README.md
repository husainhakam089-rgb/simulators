# محاكي الدارات الكهربائية

محاكي فيزيائي تفاعلي للدارات الكهربائية بواجهة عربية، مستوحى من محاكيات PhET Circuit Construction Kit — مبني بـ HTML/CSS/JavaScript خالص، بدون أي مكتبات خارجية.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا بسيطًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000/circuit-simulator/
```

## المزايا

- **سحب وإفلات** لعناصر الدارة من اللوحة الجانبية: بطارية، مصدر جهد متردد، مصباح كهربائي، مقاوم، مفتاح كهربائي.
- **توصيل الأسلاك**: اسحب من نقطة اتصال (دائرة صفراء) على أي عنصر إلى نقطة اتصال أخرى لرسم سلك.
- **محاكاة فيزيائية بسيطة للدارة**: عند اكتمال حلقة مغلقة تحتوي على مصدر جهد، يضيء أي مصباح ضمن نفس الحلقة مع أشعة متحركة، وتتحرك نقاط حمراء على الأسلاك تمثل التيار الكهربائي. وجود مقاومات إضافية يقلّل من سطوع المصباح.
- **مفتاح كهربائي تفاعلي**: النقر عليه يبدّل بين مفتوح/مغلق ويقطع أو يصل الدارة فورًا.
- **تحديد وحذف** أي عنصر أو سلك (زر السلة أو مفتاح Delete).
- **تكبير/تصغير** لمساحة العمل، وتبديل نمط العرض (إظهار/إخفاء شبكة الخلفية)، وزر مسح شامل.
- **شريط حالة سفلي** يعرض اسم الأستاذ (قابل للتعديل مباشرة) ووصفًا نصيًا حيًّا لحالة كل مفتاح وحالة الدارة (مكتملة/غير مكتملة/تضيء).

## البنية

- `index.html` — هيكل الصفحة والعناصر.
- `style.css` — التنسيق البصري (خلفية بنية متدرجة، ألوان الأسلاك والمكونات، الوضع الليلي للوحة الجانبية).
- `app.js` — كل منطق التفاعل: السحب والإفلات، رسم الأسلاك، تقييم الدارة عبر بحث BFS في رسم بياني للعقد، والتحكم بالتكبير والحذف.

## فكرة تقييم الدارة

كل مكوّن له طرفان (a وb). الأسلاك تصل بين الأطراف، والمكونات نفسها "توصل" داخليًا بين طرفيها (المفتاح فقط يوصل عندما يكون مغلقًا). لكل مصدر جهد (بطارية/جهد متردد) يُبنى رسم بياني يستثني الوصلة الداخلية للمصدر نفسه، ثم يُبحث بـ BFS هل يوجد مسار خارجي من طرفه الأول إلى طرفه الثاني. إن وُجد، تُعتبر الحلقة مكتملة، وتضيء كل المصابيح الواقعة على نفس هذه الحلقة.
