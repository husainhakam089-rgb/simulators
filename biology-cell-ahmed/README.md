# محاكي الخلية — نسخة الدكتور أحمد الحسن

نفس محاكي «الخلية» (الفصل الأول — أحياء السادس العلمي) الموجود في `biology-cell/`
بكل ما فيه. الفرق فقط في الاسم وواجهة البداية:

- **واجهة البداية:** بوستر مرسوم (`poster.svg`) بعنوان «الخلية · الفصل الأول» وخلية
  حيوانية، واسم الدكتور أحمد الحسن (دكتوراه · كلية العلوم · جامعة بغداد · ثانوية
  الإمام الحسن المجتبى (ع) للمتفوقين)، وزرّ **«ابدأ المحاكي»** المرسوم عليه يعمل
  بالماوس واللمس. البوستر رسم متّجه، فكتابته بخطوط الجهاز نفسه وتبقى واضحة بأي حجم.
- **داخل المحاكي:** «د. أحمد الحسن · دكتوراه · كلية العلوم · جامعة بغداد» أعلى
  الشاشة، والاسم في عنوان الصفحة.

ملف واحد `index.html` يعمل بلا إنترنت. يُبنى بـ
`python3 tools/packaging/make_ahmed.py biology-cell/index.html biology-cell-ahmed/poster.svg biology-cell-ahmed/index.html`.
