# محاكي الأنسجة: الفصل الثاني، أحياء السادس العلمي

نسخة باسم **د. أحمد الحسن** (مدرس أحياء · السادس العلمي). هي جزء ثاني من محاكي «الخلية»
(`biology-cell/`) وتستخدم نفس المحرّك والواجهة: مجسّمات WebGL مكتوبة داخل الملف بدون
مكتبات، وتنتقل تلقائياً للرسم بـ Canvas 2D إذا الجهاز ما يدعم WebGL. وفيها نفس لوحة
المعلومات ووضع الامتحان والرسم اليدوي والوضع النهاري وملء الشاشة وتخطيط الموبايل.
الملف `index.html` واحد ويشتغل بدون إنترنت.

> **نسخة مراجعة:** فيها التبويبان الأول والثاني. النصوص مؤقتاً مأخوذة من منهج السادس
> العلمي، وراح تتطابق حرفياً مع ملزمة الفصل الثاني وأرقام صفحاتها أول ما توصل الملزمة
> (قائمة TODO بآخر قسم المحتوى داخل الملف).

## التبويب الأول: الأنسجة المرستيمية

بيه أربع شاشات تختارها من أزرار المشهد:

| الشاشة | المجسّم والحركة | الأجزاء القابلة للضغط |
|---|---|---|
| مواقع المرستيمات | نبات ذو فلقتين ونبات عشبي ومقطع عرضي مكبّر في ساق خشبية. المرستيمات تتوهج، وأسهم تبيّن اتجاه النمو (طول، سمك، سلاميات) | المرستيم القمي للساق وللجذر، الكامبيوم الوعائي، الكامبيوم الفليني، المرستيم البيني |
| قمة الجذر | مقطع طولي بثلاث مراحل (الانقسام ← الاستطالة ← النضج) بشريط وأزرار السابقة/التالية. الكاميرا تنتقل لكل منطقة، والقلنسوة تتآكل وتتجدد | القلنسوة، مناطق الانقسام والاستطالة والنضج، الشعيرات الجذرية، البشرة الأولية، المرستيم الأساسي، الكامبيوم الأولي |
| الخلية المرستيمية | خلية تنقسم: النواة تستطيل وتنقسم، وبعدها يظهر جدار جديد | الجدار الرقيق، النواة الكبيرة، السايتوبلازم الكثيف، الفجوات الصغيرة |
| قارن | الخلية المرستيمية جنب الخلية البالغة، والفروقات تومض، وجدول الفروقات ينفتح | + الفجوة العصارية الكبيرة، المسافات البينية |

## التبويب الثاني: الأنسجة البسيطة

| الشاشة | المجسّم والحركة | الأجزاء القابلة للضغط |
|---|---|---|
| مواقعها في الساق | مقطع عرضي في ساق عشبية، والأنسجة البسيطة تتوهج بالتناوب | البشرة، الكولنكيمي، البرنكيمي، السكلرنكيمي، الحزمة الوعائية |
| البرنكيمي | خلايا حية بفجوات كبيرة، والبلاستيدات تدور مع جريان السايتوبلازم | الجدار الرقيق، الفجوة، النواة، البلاستيدات، المسافات البينية |
| الكولنكيمي | خلايا مستطيلة متغلظة الزوايا تنحني وترجع (دعامة مع مرونة) | البشرة، تغلظ الزوايا، البروتوبلاست الحي، النسيج |
| السكلرنكيمي | ألياف وخلية حجرية مقطوعة، بثلاث مراحل: خلية حية ← ترسّب اللكنين وظهور النقر ← موت البروتوبلاست | الألياف، الخلايا الحجرية، الجدار الثانوي، النقر، التجويف |
| قارن | الأنسجة الثلاثة جنب بعض مع جدول الفروقات | البرنكيمي، الكولنكيمي، السكلرنكيمي |

الجداول: أنواع المرستيمات، منشأ الأنسجة، مناطق قمة الجذر، مقارنة الخلية المرستيمية
بالخلية البالغة، مقارنة الأنسجة البسيطة. ووضع الامتحان («أشّر الأجزاء» و«اختبر نفسك») والرسم اليدوي يشتغلان
على رسوم التبويبين (7 رسوم).

مصدر البناء: `tools/tissues-src/` (قطع تنجمع بـ `build.sh` بنفس ترتيب الفصل الأول).
